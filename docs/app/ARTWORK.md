# Current character artwork

The user rejected the simplified SVG characters in this app on 15 October 2026. Use the existing detailed illustrated PNG portraits from `marketing/demo-assets/{lumo,lila,pip,nori,moki}-portrait.png`. The served copies in `docs/assets/characters/` must remain byte-identical to those masters. Tests enforce this binding.

Lumo is the ruby-red, swept-haired character with headphones, crystal controller and constellation jacket. The other four are the illustrated lilac Luna, leaf-eared green Sprout, blue wizard-hatted Nori and pink Moki with the checker scarf. The older art-direction contact sheet contains an obsolete yellow Lumo and must not be used as the current cast reference.

Use these images everywhere in the creator app: feed, chat header, chat messages, stage, world and profile. Do not substitute `docs/assets/portraits/*.svg` for expression changes, loading states or fallback art. Those vector files remain for legacy consumers only.

There is one illustrated portrait per character in this set. Expression variants and outfit changes require matching new artwork; do not imply that they exist. Atmosphere preferences and existing saved revisions remain intact. New generation must preserve this visual identity.
