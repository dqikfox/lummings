## Main surfaces

- **My Lumming:** stage, conversation, voice, wardrobe and explicit memory controls. Active character/profile always visible.
- **Create together:** contextual skills and project storyboard inside conversation. Show useful choices and outcomes rather than tool names.
- **Our creations:** private images, clips, stickers and storybooks, searchable by project/character/type; versions, export and removal.
- **Worlds and adventures:** existing authored stories alongside reviewed generated projects. Clearly distinguish authored/generated content and saved/temporary changes.
- **Crew:** invite another character into a project with explicit shared context. One coordinator controls turns; no endless autonomous chatter.
- **Grown-up / creator area:** providers, local/cloud modes, budgets, review, profiles, memory, backups and diagnostics. Creator tools can be broader than family tools.

Evolve the latest character-led app rather than importing Pixel's social dashboard. Keep strong portrait presence, Heartlight accents and readable panels. Bundle essential styles/fonts for a genuinely local mode. Mobile gets the same creative functions with progressive disclosure. Keyboard access, captions, 200% zoom and reduced-motion alternatives are baseline requirements.

## Anchor journeys

### Meet and personalise

Choose a canonical Lumming → in-character introduction → approved look/setting → conversation. No photo required. Adult-created custom characters use a separate namespace; they cannot overwrite canonical masters. Photo upload is not default child onboarding.

### Change appearance during conversation

An approved wardrobe request changes immediately and saves a version. An unfamiliar look creates a candidate: show pending state, generate from masters, review, then offer Apply. Late jobs cannot replace newer choices. Undo restores an exact previous version without paying to regenerate it.

### Imagine, animate, narrate

Resolve scene/current identity → reference-conditioned image → reviewable result. “Animate this” pins the exact accepted still and a bounded motion/duration. Narration follows script approval. Save media, lineage and project decisions. A failed clip never discards its source still.

### Make a film with the crew

Lumo outlines a three-shot rescue; Lila proposes dialogue; user chooses. Freeze continuity references, generate shots independently, review thumbnails before video spending, rerender rejected shots only, assemble timeline and add captions/audio. Show the whole bounded plan and estimate before execution. Additional shots require an explicit expansion. Benchmark multi-character composition separately.

### Grow together

“Remember that I like quiet space stories” produces an explicit preference. A memory drawer supports inspection, editing and deletion. Returning sessions adapt topics/pacing without changing core personality. Deletion invalidates summaries and active context. Avoid inferred diagnoses, dependence scores, affection penalties and guilt about leaving.

## Presence and voice

States: resting, listening, thinking, speaking, creating, waiting-for-choice, interrupted and unavailable. States correspond to real activity. Breathing animation is not live generated video.

Begin with licensed character voices and explicit playback. Add push-to-talk, streaming transcription/audio and barge-in. Stop audio promptly and discard stale segments on interruption; preserve drafts on transcription failure. Microphone permissions and audio retention are explicit. Text and captions remain available.

Prepared 2D expressions/mouth shapes provide immediate presence. Rigged 2D/3D can later support reusable outfits and camera motion. Generated stills, rigged assets and clips are separate asset classes: a picture does not contain a reusable rig. Continuous generated video is a third renderer behind the same stage/appearance interface.

## Greatest potential

Build a coherent cast and shared creative worlds, with recognisable rituals, humour, learning and user authorship. Extend into private shared projects, curated creator packs, richer rigs and an optional physical Heartlight companion after demand is demonstrated. Public feeds, stranger messaging and hardware manufacture are outside the first pilot. This keeps delivery focused while preserving the larger vision.
